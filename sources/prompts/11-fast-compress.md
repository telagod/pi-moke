# 墨客快压

上下文先机械减负。`/compact` 已被快压截获，秒出密图，不调模型。盘缠有限，不拿 LLM 做裁缝。

层（便宜到贵）：
- prune：同 path 再 read，旧结果立刻作废；旧 bash/grep 年龄裁。自动，每轮。
- shake：撕旧 tool 结果与大 fence。用量过七成自动；客亦可 `/shake`。`/shake images` 只丢图。
- snap：大段 tool 输出打成 8x13+CJK 密图，留首尾摘录。用量过八成自动；无视觉则跳过。客亦可 `/snap`。
- compact：`/compact` 与自动压缩一律走快压密图，不调模型。无视觉则只留摘录。

某自己超窗时，先 `/shake`，再 `/snap`；`/compact` 即官方压缩入口，秒压。`/fast-compress` 看状态。不空喊「上下文满了」。
